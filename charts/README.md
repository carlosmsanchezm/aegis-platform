# Aegis Helm Charts

This directory contains Helm charts for deploying Aegis services.

## Charts

### aegis-services
Control plane services (platform-api + proxy)

### aegis-spoke
Spoke/agent components (k8s-agent) that run in workload clusters

---

## Deployment Modes

### 1. Local Development (No TLS)

Deploy to local Docker Desktop without TLS (default):

```bash
# From repository root
make deploy-local
```

**Values files used:**
- `aegis-services/values/common.yaml` - Base defaults
- `aegis-services/values/local.yaml` - Local-specific config
- `aegis-spoke/values-local.yaml` - Local spoke config

**Characteristics:**
- `service.type: ClusterIP` (use port-forward)
- `tls.enabled: false`
- Single replicas
- Debug logging
- Relaxed resource limits

---

### 2. Local Development (With TLS)

Deploy to local Docker Desktop with TLS for testing:

```bash
# From repository root
make deploy-local-tls
```

**Values files used:**
- `aegis-services/values/common.yaml` - Base defaults
- `aegis-services/values/local.yaml` - Local-specific config
- `aegis-services/values/local-tls.yaml` - TLS overlay (self-signed certs)
- `aegis-spoke/values-local.yaml` - Local spoke config
- `aegis-spoke/values-local-tls.yaml` - Secure connection settings

**Characteristics:**
- `service.type: ClusterIP` (use port-forward)
- `tls.enabled: true` with self-signed certificates
- Platform API accepts TLS connections
- K8s agent connects with TLS (skip verify for self-signed)
- Proxy serves with TLS

**Testing with TLS:**
```bash
make port-forward

export GRPC_TLS=1
export GRPC_TLS_SKIP_VERIFY=1  # For self-signed certs
./scripts/e2e-platform-api.sh
```

---

### 3. Cloud/Remote Deployment (AWS/GCP/Azure)

Deploy to cloud environments with TLS:

```bash
# From terraform directory
cd terraform
./generate-helm-values.sh --tls --non-interactive
```

**Values files used:**

**aegis-services:**
1. `values/common.yaml` - Base defaults
2. `values/cloud.yaml` - Cloud-specific config (LoadBalancer, production resources)
3. `values-cloud-generated.yaml` - Auto-generated by Terraform (RDS, DNS, secrets)
4. `values-cloud-tls.yaml` - TLS overlay (enables TLS when `--tls` flag used)

**aegis-spoke:**
1. `values-cloud-generated.yaml` - Auto-generated by Terraform (platform-api endpoint, cluster ID)
2. `values-cloud-tls.yaml` - Enables secure gRPC connection when platform-api uses TLS

**Characteristics:**
- `service.type: LoadBalancer`
- `tls.enabled: true` (when `--tls` flag)
- Multiple replicas for HA
- Production logging
- Production resource limits
- RDS database backend
- Route53 DNS integration
- Self-signed TLS certificates (generated by script)

## Values File Structure

### aegis-services

```
aegis-services/
├── Chart.yaml
├── values/
│   ├── common.yaml              # Base defaults (all environments)
│   ├── local.yaml               # Local Docker Desktop config (no TLS)

├── values-cloud-tls.yaml        # Cloud TLS overlay (when --tls used)
└── values-cloud-generated.yaml  # Auto-generated (gitignored)
```

### aegis-spoke

```
aegis-spoke/
├── Chart.yaml
├── values.yaml                  # Base spoke defaults
├── values-local.yaml            # Local spoke config
├── values-local-tls.yaml        # Local TLS connection setting
├── values-cloud-tls.yaml        # Cloud TLS connection setting
└── values-cloud-generated.yaml  # Auto-generated (gitignored)
```

## File Purposes

### aegis-services/values/common.yaml
**Size:** 8.5KB
**Purpose:** Shared defaults across all environments
**Contains:** Image repos, resource limits, security contexts, probes

### aegis-services/values/local.yaml
**Size:** 6.3KB
**Purpose:** Local Docker Desktop deployment
**Contains:** `tls.enabled: false`, ClusterIP services, debug logging, relaxed limits

### aegis-services/values/cloud.yaml
**Size:** 6.7KB
**Purpose:** Cloud base configuration (TLS disabled by default)
**Contains:** LoadBalancer services, production replicas, RDS config, kubeconfig setup

### aegis-services/values-cloud-tls.yaml
**Size:** 249B (tiny!)
**Purpose:** Enable TLS overlay
**Contains:** `tls.enabled: true`, ingress config, LoadBalancer annotations

### aegis-services/values-cloud-generated.yaml
**Auto-generated** by `terraform output -raw helm_values_aegis_services`
**Contains:** RDS endpoint, DB password, JWT secret, DNS names, LoadBalancer annotations

### aegis-spoke/values.yaml
**Size:** 2.2KB
**Purpose:** Base spoke configuration
**Contains:** k8s-agent defaults, RBAC, resources

### aegis-spoke/values-local.yaml
**Size:** 379B
**Purpose:** Local spoke overrides
**Contains:** Cluster ID, platform-api endpoint (in-cluster), region, flavors

### aegis-spoke/values-cloud-tls.yaml
**Size:** 249B
**Purpose:** Enable secure gRPC connection
**Contains:** `AEGIS_CP_GRPC_INSECURE: "false"`

### aegis-spoke/values-cloud-generated.yaml
**Auto-generated** by `terraform output -raw helm_values_aegis_spoke`
**Contains:** Platform-api gRPC endpoint (with DNS), cluster ID, region, flavors, CA cert

## Layering & Merge Order

Helm merges values files from left to right, with later files overriding earlier ones.

### Cloud Deployment with TLS

```
Layer 1: values/common.yaml          (base defaults)
Layer 2: values/cloud.yaml            (cloud config, tls.enabled: false)
Layer 3: values-cloud-generated.yaml  (terraform outputs)
Layer 4: OVERRIDE_FILE                (temp: secrets, images)
Layer 5: values-cloud-tls.yaml        (tls.enabled: true ← OVERRIDES layer 2)
Layer 6: TLS_OVERRIDE_FILE            (temp: actual TLS certs)
         ↓
    Final Config: TLS enabled with certs
```

**Key insight:** `values-cloud-tls.yaml` overrides the `tls.enabled: false` from `values/cloud.yaml`.

## Troubleshooting

### Check What Values Are Actually Used

```bash
# Dry-run to see merged values
helm install --dry-run --debug aegis ./aegis-services \
  -f ./aegis-services/values/common.yaml \
  -f ./aegis-services/values/cloud.yaml \
  -f ./aegis-services/values-cloud-tls.yaml \
  --namespace aegis-system
```

### Verify TLS Status

```bash
# Platform API
kubectl get deployment aegis-services-platform-api -n aegis-system \
  -o jsonpath='{.spec.template.spec.containers[0].env[?(@.name=="GRPC_TLS_ENABLED")].value}'

# Expected: "true" when TLS enabled
```

### Check Generated Values

```bash
cat charts/aegis-services/values-cloud-generated.yaml
cat charts/aegis-spoke/values-cloud-generated.yaml
```

## Hub-and-Spoke Architecture

Aegis uses a hub-and-spoke model:

- **Hub (aegis-services)**: Central control plane with platform-api and proxy
  - Receives workload requests
  - Performs placement decisions
  - Creates AegisWorkload CRs in target clusters
  - Provides proxy access to workloads

- **Spoke (aegis-spoke)**: K8s agent runs in each workload cluster
  - Reports capacity and available flavors
  - Reconciles AegisWorkload CRs
  - Creates and manages Kubernetes Jobs
  - Sends status updates back to hub

**Deployment pattern:**
- Deploy aegis-services **once** in a central cluster (hub)
- Deploy aegis-spoke **many times** (one per workload cluster)
