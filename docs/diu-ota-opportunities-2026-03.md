- $5M ceiling is appropriate for a prototype engagement

## NOTES ON METHODOLOGY

- DIU website (diu.mil) is heavily JS-rendered (Nuxt.js); CSO details could not be extracted from static HTML. The DIU CSO details were confirmed via SAM.gov API.
- SAM.gov public API keyword search has known issues with relevance ranking; results were obtained using title-based and solicitation-number-based queries.
- NSTXL/SpEC active Descriptions of Work (DoWs) are only visible to consortium members behind a login wall.
- SOSSEC website did not return accessible solicitation data; their opportunities are also typically member-only.
- Tradewinds AI marketplace appears to have URL/structural changes; the marketplace page returned a 404 error.
- SBIR/STTR topics were searched but no open topics specifically matching DevSecOps/Kubernetes/GPU scheduling were found in the current cycle on SAM.gov. Check sbir.gov directly for open AF/Space Force SBIR topics.
